# Leal Software Solution — song prompt for Google Flow

Site analyzed: lealsolution.com. IT company — custom software, cloud, ERP
(Odoo), HVAC engineering tools, mobile/web apps. Tone: professional but
approachable, "client-first," turns tech into business growth. Blue,
clean, modern brand.

Angle: not a jingle. A "builders who solve real problems" anthem —
confident, forward-moving, corporate-but-human. Paste into Google Flow.

---

## Prompt — 30-second brand anthem

```
Style: Modern corporate uplift, confident and clean. Motivational but not
cheesy — think a tech company product-launch video, not a jingle.
110 BPM, 4/4, major key.

Instruments: Layered synths and a warm electric piano lead, punchy but soft
kick and clap, subtle plucked guitar arpeggio underneath, strings swelling
in the last section. No vocals-first EDM drop, no cheap corporate stock
sound.

Vocals: One confident, warm mixed-gender-neutral voice (or instrumental
only with a hummed hook) — clear, not shouty. Optional light background
"oohs" on the final rise.

Mood arc: quiet build -> steady momentum -> confident lift at the end.
Production: clean, modern, radio-ready but not loud/aggressive.

Lyrics (optional, instrumental works too):

[Intro - piano + arpeggio, 4 bars]

[Verse]
Every idea starts as a question
Every system starts with a need
We build the code behind the answer
Software that moves at your speed

[Chorus]
From the ground up, we design it right
Cloud to code, day into night
Leal — building trust through technology
Turning your vision into reality

[Outro - strings swell, one held chord, fade]
```

---

## Prompt — 15-second sting (for reels / video intros)

```
Style: Short confident tech-brand sting. 112 BPM. Piano + light synth,
punchy clap on the beat, strings swelling only in the last 3 seconds.
Instrumental, or one soft hummed hook. No lyrics needed.

[0:00 - piano alone, quiet]
[0:04 - clap + arpeggio enters, builds]
[0:09 - synth pad lifts, confident]
[0:12 - strings swell, end on a clean held chord, no fade]
```

---

## If first take is wrong

- Sounds like a jingle/ad: say **remove the vocal hook, make it
  instrumental, less "sing-song," more like a film score cue**.
- Too corporate-stock: say **less orchestral, more organic — real piano
  and guitar feel, not preset strings**.
- Too slow/flat: say **raise energy in the last third, add a string
  swell or synth lift before the end**.
